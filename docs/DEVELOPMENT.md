# 白酒品牌洞察：维护者技术说明

React + TypeScript + Vite 前端、Express 采集服务与 Electron 桌面应用。输入品牌名称后，查询六个公开内容来源，查看采集状态、可追溯内容及样本情感分析。

## 安装与启动

需要 Node.js 22.12 或更高版本，以及 npm。首次使用：

```bash
npm ci
```

网页开发需要两个终端，在项目目录分别运行：

```bash
npm run server
```

```bash
npm run dev
```

打开 Vite 输出的网址。开发时 `/api` 请求代理到 `127.0.0.1:3001`。后端默认仅监听本机，健康检查为 `http://127.0.0.1:3001/api/health`。

构建并运行完整网页应用：

```bash
npm run build:all
npm start
```

打开 `http://127.0.0.1:3001`。可通过环境变量 `PORT` 改变端口；`HOST` 可改变监听地址。若更改开发后端端口，需要同时修改 `vite.config.ts` 的代理目标。

启动桌面应用：

```bash
npm run electron:dev
```

桌面应用自动启动独立的本地后端，并由操作系统分配可用端口。关闭 macOS 窗口后再次打开会复用后端；退出应用会关闭服务。来源链接交由系统浏览器打开。

## 数据口径与边界

- 采集对象是公开网页和公开内容接口。网络、登录要求、访问限制、验证码以及页面结构变化可能导致某些来源暂无数据；界面会显示状态与原因。
- 采集条数仅代表本次获得的样本。页面明确提供的搜索结果数单独标注，不能当作讨论量、销量或百度指数。
- 情感分析采用关键词规则，口碑分由采集样本的情感派生。它们不是全网人群调查，也不是专业模型判断。
- 没有可靠数据的行业排名、热度指数、历史趋势及口碑维度显示“暂无数据”。不会生成随机指标、虚构报道或补造热词。
- 相关词条的权重为采集页面内出现次数，不能解读为全网出现频次或平台热度。
- 未获得发布日期的内容显示日期未知；采集时间单独记录。
- 报告查询时间使用 ISO 时间，网页以北京时间显示。缓存命中会保留原报告时间。

当前未接入需要授权的商业平台 API。要提供真实排名、历史趋势或覆盖全网的声量，需要合适的数据授权、采集历史与明确的统计方法。

## 查询稳定性

品牌名称限制为 1–50 个字符。同一品牌的并发请求合并；报告缓存 5 分钟；所有来源不可用的报告缓存 30 秒，便于稍后重试。缓存最多 100 份报告，同时最多处理 8 个不同品牌。请求繁忙时接口返回 `503` 与 `Retry-After`。

采集请求设有超时与响应体大小上限。不同来源的失败互相隔离，单个平台失败仍返回其他平台的结果。前端区分后端离线、超时与数据不可用，并支持重新查询。

## 验证与构建

```bash
npm run lint
npm run build:all
npm test
```

`build:all` 同时执行服务端严格类型检查、前端严格类型检查及生产构建。测试使用离线固定样本，覆盖聚合、请求服务、缓存及桌面服务生命周期，不会访问外部平台。

生成安装包：

```bash
npm run dist:mac
npm run dist:win
```

安装包写入 `release/`。测试版本默认使用 Electron 应用图标。分发正式安装包还需要配置对应平台的签名与公证。`release/` 中已有的旧安装包不会随着源码修改自动更新，请重新构建。

## 排查

- 网页提示后端不可用：确认 `npm run server` 正在运行，并访问健康检查接口。生产网页使用 `npm start`，避免只启动不带 API 的静态预览。
- 端口被占用：更改 `PORT`；桌面应用自动选择端口。
- 桌面应用提示模块缺失：重新运行 `npm run build:all`，再启动 Electron。
- 来源暂无数据：查看各平台状态，稍后重试。不要将没有采集到内容解释为该品牌没有讨论或没有负面舆情。

## 目录

- `src/`：搜索、报告和图表界面。
- `server/scrapers/`：各来源的公开内容采集。
- `server/services/`：聚合与请求缓存。
- `electron/`：窗口、来源链接及本地服务生命周期。
- `tests/`：离线回归测试。
- `scripts/build-server.mjs`：清理旧产物并构建 ESM 后端。
