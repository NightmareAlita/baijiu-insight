# 白酒品牌洞察：六类数据源接入需求

核验日期：2026-10-14（北京时间）。本次只查阅官方公开资料，没有注册、登录、申请权限、购买服务或发送商务消息。

这份文档用于决定接入哪些数据。**当前软件采用公开页面采样，尚未接入本文列出的官方付费/API服务。** 安装软件并不会自动获得各平台的数据权限；正式接入仍需要账号、审批、凭据和对应的软件适配。

## 1. 先确定我们需要的数据

项目可以先做“品牌相关公开内容、来源链接、采集样本数、样本情感”，再逐步增加经过授权的趋势和指数。六个平台并没有一套通用的“任意品牌全网声量与排名API”。

| 数据源 | 最小可用方案 | 更完整数据需要什么 | 排名、历史与主要边界 |
|---|---|---|---|
| 微博 | 可追溯公开帖子样本；官方微指数作为人工核对渠道 | 核验开放平台实际权限；品牌监测与历史数据需官方/获授权服务商确认 | 微指数是加权指数；任意品牌搜索、完整历史及品类榜未确认可开放 |
| 百度 | 公开搜索内容与相关词条 | 百度指数官方API接入；具体订阅、审核、指标权限待官方确认 | 搜索结果数不是搜索次数或搜索指数；按同一品牌池才能形成自建比较 |
| 抖音 | 公开可访问视频样本；或授权账号数据 | 主体认证、应用/权限审批、账号授权；自有品牌关键词另需审核 | 官方关键词搜索方案只涉及批准的自有业务关键词、最近一天；不能当作任意竞品全量搜索 |
| 小红书 | 可追溯公开笔记样本 | 品牌舆情数据需另行商务核验；账户登录API和店铺API各有不同用途 | 当前公开账户授权文档只开放基本资料，读取笔记仍属规划范围 |
| 知乎 | 官方知乎搜索API，获取公开检索结果 | 开放平台账号与Access Secret、可用额度；个人数据另走OAuth | 搜索/热榜可接，但不能据此声称获得全站品牌总声量或白酒品类排名 |
| 新闻媒体 | 选定媒体的官方RSS，或检索返回的原始报道链接 | 扩大媒体名单；必要时申请官方舆情监测API或媒体授权数据 | 报道样本、被监测报道数和转载数要分开；不存在统一新闻媒体品牌榜 |

表中“公开样本”仅表示当前可验证的内容，不承诺平台始终允许匿名访问或每次都有结果。无数据、验证码、登录限制、请求失败须继续明确显示，不能生成替代数字。

## 2. 各平台的接入要求

### 微博

**已确认：**微博官方说明微指数由提及、阅读、互动等因素加权形成。当前微指数网页版公告显示升级期间暂停访问，可使用移动版；因此它不适合作为当前桌面软件稳定的网页历史接口。[官方微指数](https://data.weibo.com/index)

**需要准备：**微博账号、开发者/应用资料、产品名称与用途、网站/回调地址；如选择开放平台接入，核验当前能批准的接口、App Key、App Secret及OAuth授权要求。官方客服仍列有应用审核、开发者信息、高级API权限和频率限制问题，但本次无法读取旧开放平台文档的完整正文，具体资质与可用权限须在官方控制台确认。[开放平台](https://open.weibo.com/)、[官方客服：开放平台相关问题](https://kefu.weibo.com/faqclassifylist?id=2930&typename=%E5%BE%AE%E5%8D%9A%E4%BA%A7%E5%93%81)

**商务核验重点：**是否提供批准品牌词的内容检索/监测；最早历史日期；是否返回提及条数、阅读量、互动量或微指数；分页及日调用额度；是否允许用于本项目和对外展示。不能把用户登录或本人账号授权视为获取任意品牌全部微博的权限。当前全品牌搜索API及价格没有得到官方公开资料确认，均列“待核验/待询价”。

### 百度：搜索内容与百度指数要分别接入

**已确认：**百度指数新官方公告为“api数据对接能力全新上线”，新首页提供API接入入口。旧帮助页仍有“不提供开放API”的旧内容，与新入口矛盾；本项目应以新入口、最新公告及实际订阅条款为准。[新首页](https://index.baidu.com/v2/index.html)、[API上线公告](https://index.baidu.com/Interface/article/detail?articleId=78)

**需要准备：**百度账号、申请主体/联系人、产品用途、品牌关键词与别名、需要的地区/终端/日期范围。接入前由官方确认申请材料、是否要求企业认证、API鉴权字段、词数/日期/调用额度、可用指标及展示权限。公告主体是图片，本次未完整核实其中具体产品规格；不臆造套餐、价格、最低消费或凭据名称，也不把其他百度云产品的AK/SK直接套用到百度指数API。

**适用范围：**取得正式指标后，可展示该指标授权范围内的真实趋势；品牌间比较必须使用同样的时间、地域、终端和关键词规则。百度网页显示的“相关结果约多少个”只能标为公开搜索结果数，不能改称搜索次数、指数、讨论量。没有核实到官方白酒品类品牌榜时，仍不能显示“官方行业排名”。

**费用：**通过官方API入口核验现行付费规格；本次不提供数值报价。须同时问清新增关键词、历史回溯、批量查询及数据导出的限制。

### 抖音

**账号与材料：**需注册开放平台账号并完成适用的主体认证，再创建应用、申请实际需要的权限。当前官方入驻表区分企业等主体与个人主体；个人主体支持小程序，移动/网站应用应核验适用主体要求。准备主体资质、应用名称/图标/用途、回调地址和品牌业务证明等，最终材料按申请页面确定。[官方入驻指南](https://developer.open-douyin.com/docs/resource/zh-CN/developer/join/join-into-developer-platform)

**两种数据路径：**

- **授权账号数据：**账号本人同意授权后，按批准能力获取该账号的作品或运营数据。需要应用凭据、已批准Scope和用户授权Token；权限随应用类型不同，不能自动扩展到所有用户。[官方权限概述](https://partner.open-douyin.com/docs/resource/zh-CN/developer/introduction/type-and-permission)
- **与自身业务相关的视频：**官方关键词视频管理方案要求关键词与自身业务有关，不允许通用品类词或竞品品牌词，搜索仅返回最近一天发布的公开视频；接口注明需要权限申请及用户授权。控制台是否仍可申请、品牌词如何证明须实际核验。[接入方案](https://open.douyin.com/platform/resource/docs/ability/search-management/video/)、[关键词搜索接口](https://open.douyin.com/platform/resource/docs/openapi/search-management/keywords-video-list/keywords-video/)

**重要更新：**官方公告已停止移动/网站应用多项热点、达人/视频/话题等榜单权限的新申请，并开始回收已有权限。旧API文档仍在线，不代表新项目可以开通这些能力。[权限调整公告](https://developer.open-douyin.com/forum/bulletin/post/672d828be9f6234d658c8dd2)

**结论与费用：**适合先核验自有品牌或授权账号监测；任意白酒竞品完整声量、全历史趋势、行业排名另需明确的合作方案。当前可申请范围、额度和费用按控制台/官方确认，不预设免费或报价。

### 小红书

**账户开放平台：**创建应用，提交主体、名称、图标、平台与授权范围并经审核；获得app_id及适用的应用凭据，然后由用户确认OAuth授权。当前公开Scope文档仅开放basic_info，读取笔记read_notes仍标为规划中。[快速接入](https://openaccount.xiaohongshu.com/docs/quick-start)、[授权范围](https://openaccount.xiaohongshu.com/docs/scope)

**电商开放平台：**第三方开发者/商家自研需先完成资质审核；商家自研须绑定符合条件的店铺主账号。API主要围绕授权店铺的商品、库存、订单、物流等能力；它不能替代社区笔记的品牌舆情搜索。[开发者指南](https://open.xiaohongshu.com/document/developer/file/32)、[应用类目与权限](https://open.xiaohongshu.com/document/developer/file/33)

**本项目仍需确认：**官方是否能提供指定品牌的公开笔记搜索、互动统计、历史监测或批准的数据合作；需要哪些企业/品牌证明；覆盖期、配额、导出及商业使用范围。不能凭账户登录授权获得任意品牌的全站笔记。没有确认到可自助开通的此类API，费用与方案均待官方询问。

### 知乎

**已确认的通用路径：**官方数据开放平台面向所有用户，个人中心可创建Access Secret，用Bearer方式调用知乎搜索、全网搜索、热榜等接口；请求还需秒级时间戳。官方首页列有试用额度与服务价格入口，具体可用额度/价格应以账号和对应接口为准。公开搜索与读取授权用户个人数据是不同能力。[官方数据开放平台](https://developer.zhihu.com/)、[文档入口](https://developer.zhihu.com/docs)

**需要准备：**知乎开放平台账号、Access Secret、检索品牌词及别名、需要的返回内容和频率。如要接入第三方登录、个人创作/关注/收藏，再按OAuth文档申请适用应用和用户授权，不能用通用搜索凭据冒充他人授权。

**范围：**可先把公开品牌检索结果用于内容样本及来源追踪；没有验证到完整品牌提及总量、无限历史或白酒品牌官方榜。排序靠前的文章不等于品牌排名。具体单次结果数、翻页、时间筛选和计费边界须在正式接入前核对对应接口文档。

### 新闻媒体

**最小方案：**先选择明确的媒体名单，接入媒体自身公开RSS，保留原链接、实际发布时间、来源和采集时间。中国新闻网官方RSS页提供财经、即时等频道；公开RSS入口无需本文列出的应用密钥。RSS不是完整历史库，实际更新、可访问性及商业使用范围仍需核验。[中新网官方RSS](https://www.chinanews.com.cn/rss/)

**扩展方案：**百度官方舆情服务提供监测API。其操作指南要求智能云账号、实名认证、服务申请与AK/SK鉴权；官方文档还列出按监测任务获取媒体声量趋势和热门舆情榜单。该榜单是任务范围内的内容榜，并非白酒品牌行业排名。[操作指南](https://aca.bce.baidu.com/doc/TRENDS/s/Gjwvygmqb)、[舆情分析API](https://cloud.baidu.com/doc/TRENDS/s/skmyii9bo)

上述舆情文档部分更新较早；概览还写有云服务器部署要求，正式采用前须确认现行准入、部署方式、费用和覆盖范围。[官方服务概览](https://aca.bce.baidu.com/doc/TRENDS/index.html)

**需要准备：**品牌检索式、媒体白名单、监测任务范围、历史需求、报告/原文展示范围。如需文章全文、批量历史或对外再分发，应向数据提供方确认相应授权。报价、历史期和检索额度待询价；不要假定一个新闻服务覆盖所有中文媒体。

## 3. 材料与凭据清单

以下是接入规划字段，**不是当前软件已支持的设置项，也不是要求您把真实密钥写进文档**。获得权限后再按官方文档实施配置。

| 类别 | 应准备的内容 |
|---|---|
| 主体与产品资料 | 企业/个人适用身份、主体证明、联系人；应用名称/图标/简介；使用场景、网站与OAuth回调地址；平台要求的隐私政策或数据使用说明 |
| 业务证明 | 自有品牌、商标或授权关系，拟申请品牌词；抖音不得把竞品词包装为自有业务词 |
| 微博 | App Key、App Secret、回调地址、批准接口/权限；用户授权Token按适用接口配置，当前要求待控制台确认 |
| 百度指数 | 申请账号、订阅标识、API凭据及签名要求，名称与规格由官方提供；不套用其他服务密钥 |
| 抖音 | 应用client key/secret、批准Scope、授权账号标识及用户Token；具体字段按应用类型和接口确定 |
| 小红书 | 账户平台app_id及适用凭据/Scope；电商平台另有应用与店铺授权凭据，不能混用 |
| 知乎 | Access Secret；如果接入个人数据，另需适用OAuth应用与授权凭据 |
| 新闻 | RSS源地址/媒体白名单；如使用百度舆情API，按其服务文档配置AK/SK和监测任务标识 |

真实密钥、Token、登录Cookie与用户资料应保存在私有配置/服务端，不放入GitHub源码、安装包公共配置或本文件。软件公开分发时，开发者应用密钥不应成为所有安装用户共享且可提取的凭据。

## 4. 统一数据口径，才能形成可信报告

| 名称 | 本项目应怎样显示 |
|---|---|
| 采集样本数 | 当前实际收录并去重的公开内容条数，注明来源、时间、是否仅取前若干条 |
| 搜索结果数 | 来源页面或接口明确给出的结果计数；搜索返回的数组长度不等于结果总数 |
| 阅读/播放/曝光量 | 指定内容或账号、指定时段下的指标；不能当成讨论条数 |
| 官方指数 | 保留官方指标名称、单位、时间/地域/终端及版本；不能与其他平台指数直接相加 |
| 样本情感 | 对标题/摘要或已授权正文的分析，注明方法、样本量和限制；不是全体消费者口碑 |
| 趋势 | 只绘制取得的历史序列；采集失败是缺失，不是零；禁止补造过去30天 |
| 排名 | 先固定品牌池和统一指标/时间；如自行计算，明确写“所选品牌池内排名”，不称官方行业榜 |

开始接入前应固定：品牌名单与别名、公司/产品边界、地域、统计时区（建议北京时间）、日期范围、每日更新频率、转载/重复内容的处理规则。建议先以近30天为产品目标；源只提供一天或没有历史时，必须如实显示这一限制。持续采集可逐渐积累自己的历史，但不能补回未取得的旧数据。

跨平台出现相同报道或搬运内容时，应标明可能重复；不同数据源的样本数不能简单拼成“全网真实声量”。模型或规则给出的情感分数应与平台官方指数分开展示。

## 5. 分阶段接入建议

1. **先完成内容样本层。** 保留当前软件真实来源和不可用状态；优先评估知乎官方搜索和少量官方新闻RSS，验证目标品牌的命中情况。这里是下一步接入建议，当前软件尚未新增这些API/RSS适配。
2. **再取得一个可靠历史指标。** 优先核验百度指数新API的正式规格；根据自有品牌运营需求核验抖音授权账号数据。只有取得可用历史后才启用趋势。
3. **最后评估品牌监测采购。** 向微博、小红书及适用舆情服务确认批准品牌词、历史、覆盖、配额、导出和用途，并拿真实返回样本验证；不以宣传的“全网”二字代替覆盖证明。
4. **有统一品牌池后再做比较。** 每个平台先独立比较，指标和缺失处理固定后，才考虑公开说明方法的综合分数。缺乏有效可比数据时保留排名/热度/雷达空状态。

需要用户提供或决定的是：监测品牌及别名、是否拥有品牌/账号授权、是否有适用企业主体、需要的历史长度、使用人数、是否对外展示、可接受预算上限。预算确认后再索取官方报价，不在本阶段购买。

## 6. 核验程度与待确认事项

- **可由官方公开资料确认：**百度指数新API已上线；知乎存在通用搜索数据平台；抖音自有关键词搜索的限制和榜单权限调整；小红书账户权限与电商权限的区别；微博微指数定义及网页版暂停公告；中新网官方RSS；百度舆情API文档路径。
- **仍待账号/商务核验：**各平台当前能批准给本项目的权限、企业/个人适用资质、精确配额和价格、关键词覆盖、历史深度、完整结果数、导出与展示授权。
- **本次没有做：**登录控制台、申请应用/权限、实际付费API联调或批量抓取。因此文档确认的是公开接入条件与边界，不是“六个平台已经全部打通”。

正式接入时应保存官方批准范围和数据字段样例，再根据实际返回调整软件。账号审批与数据合同变化后，需重新核对本文件中的范围和限制。
